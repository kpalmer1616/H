# QuotePilot AI — working full-stack starter

This is **application code**, not a static mockup. It includes real user accounts, server-side quote generation, persistent usage balances, Stripe Checkout session creation, subscription and credit-pack webhook handling, Stripe customer billing portal, and a mobile-friendly dashboard. It is **not live** and has **not been integration-tested against your accounts**. Do not charge customers until you complete the launch checklist and test payments.

## Pricing

| Product | Charge | Allowance |
| --- | --- | --- |
| Pro | $9.99/month | 25 quotes per paid billing cycle |
| Business | $19.99/month | 100 quotes per paid billing cycle |
| Credit pack | $4.99 | 5 quotes |
| Credit pack | $14.99 | 20 quotes |
| Credit pack | $29.99 | 50 quotes |

No free customer quotes. No PDF downloads or print-estimate feature. Unused prepaid credits remain on the account; monthly allowance is replenished on successful invoice payments. The backend consumes the monthly allowance first, then prepaid credits.

## Architecture

- Cloudflare Worker: `src/worker.js` (authentication, Stripe checkout, webhook, quotes)
- Cloudflare D1: `sql/schema.sql` (accounts, sessions, balances, quotes, processed Stripe events)
- Worker static assets: `public/` (homepage, registration, login, dashboard, pricing)
- Passwords: PBKDF2 SHA-256 with 210,000 iterations and per-user random salt
- Sessions: random HttpOnly/Secure/SameSite=Lax cookies, hashed session tokens in D1
- Quote allowance: conditional atomic SQL UPDATE, so parallel quote requests cannot overspend
- Stripe webhook: HMAC signature verification and duplicate-event handling

**AI branding note:** The core pricing calculations are deterministic, not generated by a paid AI model. This avoids unpredictable costs and fabricated calculations. No live AI model is integrated.

## Setup (requires a computer or GitHub workflow; iPhone-only deployment is harder)

1. Create a free Cloudflare account and Stripe account. Stripe has transaction fees. Free Cloudflare services have usage limits.
2. Install Node.js (LTS), then run `npm install` in this folder.
3. Log in with `npx wrangler login`.
4. Create database: `npx wrangler d1 create quotepilot-db`.
5. Paste the returned D1 database ID into `wrangler.toml`.
6. Create tables: `npm run db:remote`.
7. In Stripe **test mode**, create five prices: recurring $9.99 and $19.99 monthly, and one-time $4.99, $14.99, $29.99. Copy each `price_...` ID.
8. Set the price IDs as Worker environment variables (in Cloudflare dashboard or `wrangler secret put`, though they are not secret): `STRIPE_PRICE_PRO`, `STRIPE_PRICE_BUSINESS`, `STRIPE_PRICE_PACK5`, `STRIPE_PRICE_PACK20`, `STRIPE_PRICE_PACK50`.
9. Set secret `STRIPE_SECRET_KEY` with `npx wrangler secret put STRIPE_SECRET_KEY` (use test key initially).
10. Deploy with `npm run deploy`. This creates a `workers.dev` site, separate from your existing Pages deployment. Visit the returned URL.
11. In Stripe create a webhook endpoint `https://YOUR-WORKER-URL/api/stripe/webhook`, subscribing to `checkout.session.completed`, `customer.subscription.created`, `customer.subscription.updated`, `customer.subscription.deleted`, `invoice.paid`.
12. Copy the webhook signing secret (`whsec_...`) and set `npx wrangler secret put STRIPE_WEBHOOK_SECRET`.
13. In Stripe activate/configure the customer portal for cancellation and payment-method changes.
14. Test registration, login, quote blocking before payment, all five Stripe checkout products, subscription replenishment, one-time credits, subscription cancellation, failed payment, duplicate webhook delivery, and usage exhaustion.
15. Replace draft privacy and terms pages and provide support email, refund policy, business identity, and payment disclosures. Configure domain, account recovery, bot/rate-limit protection, support processes, and monitoring before public launch.
16. Only then switch to live Stripe keys and live Stripe prices and webhook secret. Re-run tests with small real purchases.

**Important:** Stripe payment links alone will not activate user entitlements. Use the Checkout session API built into this Worker and the matching webhook. All Stripe products must use the expected price amounts; for prepaid credits, the webhook verifies the charged amount and currency. Do not enable coupon codes until discounts are deliberately supported.

## Known launch gaps

- No email verification, password reset, MFA, CAPTCHA, or automated account-recovery flow yet.
- No customer deletion workflow, admin dashboard, usage analytics, support email integration, or tax configuration.
- No automated handling of all possible Stripe billing edge cases (proration, chargebacks, refunds, multiple simultaneous subscriptions, dispute reversals). Review Stripe events and add robust entitlement reconciliation before public scale.
- A quote is counted when successfully saved, but a database failure during the save requires compensating credit; rare concurrent failure edge cases should be integration-tested.
- Stripe and Cloudflare quotas, transaction fees, and legal requirements vary. Free hosting does not mean fee-free revenue.
- No verified production deployment or Stripe account connection has occurred.

## Developer checks

Run `npm run check` for JavaScript syntax validation. Test endpoints on a local Wrangler instance with a local D1 database (`npm run db:local`, `npm run dev`). Stripe test webhooks must be configured against an externally reachable endpoint or forwarded appropriately.
